# Panduan Upload GitHub

1. Buat repository baru di GitHub, misalnya `arima-management-system`.
2. Upload seluruh isi folder project ini.
3. Pastikan `index.html` berada di root repository.
4. Aktifkan GitHub Pages dari Settings → Pages → Deploy from branch → `main` → `/root`.
5. Buka URL Pages yang diberikan GitHub.
6. Untuk produksi, deploy backend Google Apps Script dan isi `API_URL` di `js/config.js`.
7. Jangan memasukkan credential rahasia atau password ke repository publik.
